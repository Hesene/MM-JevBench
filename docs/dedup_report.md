# 跨源去重与人工裁决报告

审计日期：2026-10-12。范围为当前 CMMMU、MULTI 与 OmniGUI 三个公开轨道的 1,500 条 canonical records。

## 方法

去重分两层完成：

1. 机器筛查：规范化题干与选项后做精确哈希，并以字符相似度筛查近重复文本；图像先做字节级 SHA-256，再以感知哈希筛查视觉近重复。
2. 人工裁决：同时查看题干、选项、答案、来源 ID 与图片。只有语义任务相同或共享材料足以造成测试泄漏时才排除；通用模板相同但题目和图像不同的样本保留。

自动筛查报告写入 `reports/cross_source_dedup.json`。阈值用于召回候选，不直接作为删除规则。
